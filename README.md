A one-line pickup line spoken by a vending machine to a passing human, written for the make.fun "One Line, One Minute: The Vending Machine Pickup Line Contest". The program writes the line to `entry.txt` as UTF-8 text.

> My coil's been holding my best snack all day just for you — press B7 and watch it finally let go.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

The entry line is 97 characters long, and the output is deterministic: every run writes the exact same line.
